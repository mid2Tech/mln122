# MLN122 - Web Luyện Thi & Học Bài (Kinh Tế Chính Trị Mác - Lênin)

Website ôn tập trắc nghiệm môn **MLN122** với ngân hàng **526 câu hỏi**, chia thành từng đề 60 câu, hỗ trợ lưu trữ tiến trình tự động vào `localStorage` (không lo mất bài khi F5 hoặc tắt trình duyệt).

Giao diện mô phỏng 100% hệ thống thi trắc nghiệm FPT / Mediasite / fuoverflow.

## 🚀 Tính năng nổi bật

- **Chia đề 60 câu**:
  - Đề 1 (Câu 1 - 60)
  - Đề 2 (Câu 61 - 120)
  - Đề 3 (Câu 121 - 180)
  - Đề 4 (Câu 181 - 240)
  - Đề 5 (Câu 241 - 300)
  - Đề 6 (Câu 301 - 360)
  - Đề 7 (Câu 361 - 420)
  - Đề 8 (Câu 421 - 480)
  - Đề 9 (Câu 481 - 526)
  - Tất cả câu hỏi (526 câu)
- **Tự động lưu tiến trình (F5 không mất)**: Mọi câu trả lời, câu đang làm dở, điểm số đều được lưu trữ trực tiếp trên trình duyệt.
- **Phản hồi tức thì**: Báo đúng / sai ngay khi chọn đáp án, giải thích chi tiết và các dạng biến thể *(Kiểu hỏi khác)*.
- **Hỗ trợ làm lại câu sai**: Nộp bài xem kết quả và có chế độ làm lại riêng những câu đã chọn sai.
- **Chế độ Học bài**: Trang tra cứu nhanh và hiển thị sẵn đáp án đúng kèm công cụ tìm kiếm từ khóa câu hỏi.
- **Phím tắt nhanh**:
  - `A`, `B`, `C`, `D`: Chọn đáp án.
  - `←` / `→`: Chuyển câu trước / câu sau.

## 📁 Cấu trúc thư mục

- `index.html`: Giao diện chính luyện thi theo đề.
- `MLN122-hoc-bai.html`: Giao diện học bài, tra cứu đáp án trực tiếp.
- `questions.js`: Ngân hàng 526 câu hỏi đã chuẩn hóa và chia đề.
- `MLN122-FINAL.docx`: File tài liệu gốc câu hỏi ôn thi.
